# fronted-design.md — Inkite 前端界面与折纸动效设计规格

> **定位**：本文件是 Inkite 单人开发期 **前端视觉 / 交互 / 动效的设计事实来源**，与 `docs/single-TODO.md`（行动指引）、`docs/schema-design/design.md`（数据模型）配套。
> **本文件只给"设计规格"，不给实现代码**——具体到颜色值、尺寸、时长、缓动曲线、Lottie 资源命名、动效触发时机与状态机，让 AI 能据此直接产出 Flutter 代码。
> **主题母题**：折纸（Origami）。一切视觉与动效都从"一张纸如何被折、被翻、被展开、被放飞"推导，避免脱离母题的炫技。
> **平台**：Windows 桌面为主交付（鼠标 + 键盘为一等输入），同代码兼容 Android。所有交互须在**鼠标 hover / click / 滚轮**下成立，不依赖触摸手势。
> **技术约束对齐**：页面切换走 GoRouter 已集成的 `CustomTransitionPage` + `Transform` 模拟折叠；小图标与加载动效走 **Lottie**（素材库丰富）；客户端不直连 Storage，折纸图片只用 Firestore 给的 `imageUrl` 经 `Image.network` 显示（`CLAUDE.md` §7）。

---

## 0. 设计原则（动工前先读）

1. **折纸是动词，不是贴图**。每个关键转场都应能用"纸的物理动作"描述：翻页=书页折叠，进展览厅=纸鸟飞过，保存=纸张合拢，发布=纸鸟飞出，展开他人文章=折纸摊开。视觉静态元素（图标）也用折纸造型（箱子、纸鸟、笔、放大镜）。
2. **动效服务于反馈，不阻塞操作**。任何动画都有"可跳过 / 不挡输入"的底线：超过 600ms 的转场必须允许期间继续操作或快速结束（见 §7 性能与降级）。演示视频是最终交付，动效要"录起来好看"但不能拖慢节奏。
3. **皮肤是一等公民**。纸张皮肤与墨水皮肤从第一版就预留切换接口（§8），即使首版只有 1 套默认皮肤。所有颜色、纹理、笔触不得在 widget 里硬编码，一律走皮肤令牌（design token）。
4. **降级永远有兜底**。Lottie 资源缺失 → 退静态图标；低性能设备 / 关闭动画偏好 → 转场退为标准淡入淡出；动画不该成为功能阻塞点。
5. **复用现有骨架**。4 Tab（写作 / 广场 / 展览厅 / 我的）与 `ShellRoute` 结构不变；新页作为子路由挂入（`/writing/editor`、`/square/story/:id` 等），动效在路由层与组件层分层实现。

## 1. 视觉基调与设计令牌（Design Tokens）

> 所有数值是**默认皮肤（"宣纸 · 松烟墨"）**的取值。皮肤切换时这些令牌被整体替换（§8）。AI 实现时应把它们集中到一处主题定义，不在页面内散落字面量。

### 1.1 色彩令牌

母题取"宣纸 + 松烟墨 + 一点朱砂"，低饱和、暖白底、克制点缀。

| 令牌名 | 语义 | 默认值（浅色） | 用途 |
|--------|------|----------------|------|
| `paperBase` | 纸面主背景 | `#F5F1E8`（宣纸暖白） | 全局 Scaffold 背景、纸张表面 |
| `paperShade` | 纸面阴影 / 折痕暗面 | `#E7E0D0` | 折叠转场暗面、卡片分隔 |
| `paperHighlight` | 纸面高光 / 折痕亮面 | `#FFFDF7` | 折叠转场亮面、纸张高光边 |
| `inkPrimary` | 主墨色（正文 / 主文字） | `#2B2622`（松烟墨） | 标题、正文、主图标线条 |
| `inkSecondary` | 次墨色（辅助文字） | `#6B6258` | 摘要、时间戳、占位提示 |
| `inkFaint` | 极淡墨（分隔线 / 禁用） | `#C9C0B2` | 分隔线、disabled 状态 |
| `accentVermilion` | 朱砂点缀 | `#C2410C` | 主操作按钮、点赞选中、名次 Top3 |
| `accentSeal` | 印章红（强调徽记） | `#9A2D1F` | "已发布"印章、官方挑战徽标 |
| `surfaceCard` | 卡片底 | `#FBF8F0` | 故事卡片、详情卡片 |
| `goldLeaf` | 金箔（解锁 / 奖励） | `#B8893A` | 魔法墨水解锁、折纸藏品边框 |

> **暗色皮肤**（预留，非首版必做）：`paperBase→#1E1B17`、`inkPrimary→#EDE6D8`，朱砂金箔保留。切换由皮肤令牌整体替换实现，页面无需改逻辑。

### 1.2 字体与字号

| 角色 | 字号 / 字重 | 行高 | 说明 |
|------|------------|------|------|
| 大标题（页眉 / 挑战词） | 28 / SemiBold | 1.3 | 三词挑战、页面主标题 |
| 文章标题 | 20 / Medium | 1.4 | 编辑器标题、详情页标题 |
| 正文 | 16 / Regular | 1.75 | 编辑器正文、详情正文，行高偏大以贴近"稿纸"阅读感 |
| 摘要 / 卡片副文 | 14 / Regular | 1.5 | 广场卡片摘要、作者行 |
| 辅助 / 时间戳 | 12 / Regular | 1.4 | 时间、计数、uid |

中文优先衬线或仿宋类（贴合"书写"母题），西文与数字用同族无衬线兜底；具体字体文件由实现期选定并随皮肤可换。

### 1.3 形状 / 间距 / 海拔

- 圆角：卡片 `12`，按钮 `10`，对话框 `16`，纸鸟 / 箱子图标按其造型自然边缘。
- 间距基数：`4` 的倍数（4 / 8 / 12 / 16 / 24 / 32）。页面外边距桌面端 `24`，列表项间距 `12`。
- 海拔：纸面主张"薄而轻"，卡片用极淡投影（模拟纸张离桌一点点）而非 Material 厚重阴影；折叠转场期间用 `paperShade`/`paperHighlight` 模拟折痕受光，而非靠 elevation。

### 1.4 通用动效曲线与时长令牌

> 折纸动作偏"硬挺纸张"，缓动应带一点"折到位的顿挫"，不要弹性过软。

| 令牌 | 值（建议） | 用途 |
|------|-----------|------|
| `durInstant` | 120ms | hover / 按下态反馈 |
| `durFold` | 420ms | 翻页折叠主转场单段 |
| `durBirdFly` | 900ms | 纸鸟飞过 / 飞出 |
| `durUnfold` | 520ms | 他人文章展开 |
| `durSaveFold` | 600ms | 保存合拢 |
| `curveFold` | `Cubic(0.45, 0.05, 0.30, 1.0)`（折到位顿挫） | 折叠类 |
| `curveFly` | `Cubic(0.22, 0.61, 0.36, 1.0)`（起飞加速→滑翔） | 纸鸟类 |
| `curveUnfold` | `easeOutCubic` | 展开类 |

## 2. 折纸图标与加载动效体系（方案 3：Lottie）

> 选型：**小图标 / 加载动效统一用 Lottie**（素材库丰富，便于换肤与统一节奏）。每个 Lottie 资源约定一套命名 + 状态 + 降级静态图，AI 据此接入 `lottie` 包并控制播放。

### 2.1 资源命名与放置约定

- 目录：`assets/lottie/`（在 `pubspec.yaml` 的 `assets` 注册；引入 `lottie` 依赖属实现期改动，本文件不写代码）。
- 命名：`<语义>_<状态/动作>.json`，全小写下划线。例：`bird_fly.json`、`box_open.json`、`pen_write.json`、`loading_brush.json`。
- 每个动效图标须配一张**静态兜底**（`assets/icons/<语义>.svg` 或 PNG），用于 Lottie 加载失败或低性能降级。

### 2.2 图标清单（折纸造型）

| 语义 | Lottie 资源 | 静态兜底 | 出现位置 | 动作描述 |
|------|------------|----------|----------|----------|
| 纸鸟（文章 / 发布） | `bird_idle.json` / `bird_fly.json` | `bird.svg` | 文件树中的文章节点、发布动效、展览厅 | idle 轻微振翅；fly 振翅 + 位移 |
| 折纸箱（文件夹） | `box_closed.json` / `box_open.json` | `box.svg` | 写作界面左侧文件树文件夹节点 | 展开文件夹时盒盖掀开 |
| 折纸笔（写作模式） | `pen_idle.json` / `pen_write.json` | `pen.svg` | 编辑器右上模式切换 | 进入写作模式笔尖落下书写 |
| 放大镜（编辑 / 校阅模式） | `lens_idle.json` | `lens.svg` | 编辑器右上模式切换 | 进入编辑/校阅模式镜片微缩放 |
| 加载（毛笔运笔） | `loading_brush.json` | 系统 `CircularProgressIndicator` | 全局异步加载 | 毛笔来回运笔成环，替代默认转圈 |
| 点赞（折纸心 / 朱砂点） | `like_tap.json` | `heart.svg` | 卡片 / 详情点赞 | 点击迸出一小簇朱砂折痕 |
| 空态（折纸留白） | `empty_paper.json` | `empty.svg` | 列表 / 画廊空态 | 一张纸缓缓落下停住 |
| 解锁（金箔点亮） | `unlock_gold.json` | `lock.svg` | 魔法墨水 / 主题房间解锁 | 金箔从锁形展开 |

### 2.3 加载动效统一规范

- 全局任何 `StreamBuilder` / `FutureBuilder` 的 `waiting` 态，统一用 `loading_brush.json`（尺寸 48×48，居中），而非默认 `CircularProgressIndicator`。
- 列表首屏加载用 3–4 个**骨架纸卡**（`paperShade` 底 + 微微呼吸透明度），而非整屏转圈，减少"突然弹出"。
- 加载超过约 8s 显示一行 `inkSecondary` 文案"正在铺纸……"，避免无限静默。
- 降级：Lottie 资源缺失或解码失败 → 自动退回系统指示器，不报错、不空白。

## 3. 页面切换折叠动画（方案 1：CustomTransitionPage 翻书折叠）

> 选型：页面切换走 GoRouter 已集成的 `CustomTransitionPage`，用 `Transform`（`Matrix4` 透视 + `rotateX/rotateY`）模拟书页折叠。下面给出**统一转场规格**与**逐场景参数**，AI 可据此直接产出 `transitionsBuilder`。

### 3.1 统一翻书折叠转场（默认页面切换）

**母题**：相邻页面像一本书的两页。前进 = 当前页以**右边缘为轴向左翻折**离场，新页从背面翻正进场；后退方向相反（以左边缘为轴）。

**几何与参数**

- 透视：`Matrix4..setEntry(3, 2, 0.0012)`（轻微近大远小，0.0012 量级，过大则畸变）。
- 旋转轴：纵向翻书绕 **Y 轴**（`rotateY`）；§3.4 的"翻书阅读"等竖向场景可绕 X 轴。
- 离场页：`rotateY` 0 → +90°（前进）/ 0 → −90°（后退），`alignment` 设在翻折边（前进取 `centerRight`）。配合一层从 `paperHighlight` 扫到 `paperShade` 的折痕受光渐变叠加，模拟纸面转动受光。
- 进场页：从 −90° → 0（前进），与离场页**错开 50%** 衔接（离场过半时进场开始翻正），避免中途露出空白背景；背景铺 `paperBase` 兜底。
- 时长：单段 `durFold`（420ms），整段含错峰约 600–650ms。
- 缓动：`curveFold`（折到位顿挫）。
- 输入：转场期间锁输入（防误触双跳），结束即解锁；若用户在 200ms 内连续切 Tab，则**打断当前转场直接切**（不排队堆叠）。

**方向判定**：Tab 横向切换（写作↔广场↔展览厅↔我的）按 Tab 索引大小决定左/右翻；进入子页（落地页→编辑器、列表→详情）一律视为"前进"（向左翻进）。

### 3.2 底部 Tab 切换

- 复用 §3.1 翻书折叠，方向由 Tab 索引差正负决定（目标索引大→向左翻进，小→向右翻退）。
- 选中 Tab 的图标做一次 `durInstant` 的微缩放（0.92→1.0）点按反馈，配合 `inkPrimary`→`accentVermilion` 选中色变化。
- **特例**：切到"展览厅"Tab 时，翻书折叠完成的同时叠加 §4 的"纸鸟飞过"入场（两动效串行：先翻页落定，再放鸟）。

### 3.3 落地页 → 子页（编辑器 / 详情）

- 统一前进向翻书折叠。
- 详情页（`/square/story/:id`）进入时，§6 的"折纸展开"动画作为**页面内主体的二段动效**：先翻书折叠把详情页翻正（容器级），再由文章卡片自身做摊开（内容级），见 §6。

### 3.4 翻书阅读纵深（可选增强，低优先）

- 在故事详情或长文阅读，可把横向翻书改为**纵向翻页**（绕 X 轴，从下往上翻），更贴近"翻稿纸"。优先级 P2，资源紧张可不做，仅保留接口位（转场方向参数化：`FoldAxis { horizontal, vertical }`）。

### 3.5 转场降级

- 系统"减少动态效果"偏好开启、或检测到掉帧 → 全部翻书折叠退为 `durInstant` 的纯 `FadeTransition`。
- 转场参数（轴 / 方向 / 时长 / 是否折痕受光）应集中为一个转场配置对象，便于全局一键降级与皮肤联动。

## 4. 进入展览厅 · 纸鸟飞过

**触发**：路由进入 `/gallery`（无论从 Tab 还是其他入口），且满足"本次会话首次进入或距上次进入超过约 30s"才放（避免来回切 Tab 反复触发，频繁则只做轻量版）。

**动效编排**

1. 容器级翻书折叠（§3.2 特例）先把展览厅页翻正落定。
2. 落定瞬间，一只 `bird_fly.json` 折纸鸟从**屏幕左下**起飞，沿一条**贝塞尔滑翔弧线**飞向**右上**离场，约 `durBirdFly`（900ms），缓动 `curveFly`（起飞加速→末段滑翔减速）。
3. 鸟飞过路径上可带极淡的"折痕轨迹"残影（2–3 帧拖尾，`inkFaint`），强化纸的轻盈感。
4. 鸟飞出后，画廊网格内容做一次轻微 `durFold` 的错峰淡入（自上而下，每行延迟 60ms），像被风掀起后落定。

**层级**：纸鸟在内容之上的 `Overlay` 层飞行，不参与列表布局、不挡点击（飞行期间 `IgnorePointer`）。
**频繁降级**：30s 内再次进入只做画廊内容错峰淡入，不再放鸟。
**资源缺失降级**：`bird_fly.json` 缺失 → 跳过纸鸟，仅保留内容错峰淡入。

## 5. 书写界面 · 双栏（文件树 / 内容预览）+ 模式切换

> 目标形态：**类 Typora**。左侧文件树（折纸箱 = 文件夹、纸鸟 = 文章），右侧内容区；右上角"笔 = 写作模式 / 放大镜 = 编辑（校阅）模式"，进入后可切换，且写作模式下**隐藏左侧文件树**专注书写。
>
> 数据来源对齐 `single-TODO.md` §0.2：文章列表 = `StoryRepository.streamMyStories(uid)`；草稿 / 已发布按 `visibility` + `publishedToSquare` 区分。文件树是"我的故事"的折纸化表达（T2.4 的视觉承载）。

### 5.1 整体布局（默认 = 编辑/校阅模式，双栏）

```
┌──────────────────────────────────────────────────────────┐
│  写作                                  [🖋 写作] [🔍 校阅]   │  ← 顶栏：标题 + 右上模式切换
├───────────────┬──────────────────────────────────────────┤
│  文件树(左)    │  内容预览 / 编辑区 (右)                     │
│               │                                            │
│ 📦 我的故事    │   # 标题                                   │
│  ├ 📦 草稿     │                                            │
│  │  └ 🕊 未命名 │   正文预览（Markdown 渲染 / 富文本）        │
│  └ 📦 已发布   │                                            │
│     ├ 🕊 故事A │                                            │
│     └ 🕊 故事B │                                            │
│               │                                            │
└───────────────┴──────────────────────────────────────────┘
```

- 左栏宽度桌面端默认 `280`，可拖拽分隔条调节（`220–420` 区间），分隔条 hover 显 `accentVermilion` 细线。
- **折纸箱（文件夹）**：用 `box_closed/box_open` Lottie。两层固定分组——"草稿"（`visibility=private`）与"已发布"（`publishedToSquare=true`）；展开/折叠时盒盖掀开/合上（`box_open` 正放/倒放），子项做 `durFold` 高度展开。
- **纸鸟（文章节点）**：每篇 story 一个 `bird_idle` 小图标 + 标题；hover 时纸鸟轻振翅（idle 循环加速一档），选中项底色 `surfaceCard` + 左侧 `accentVermilion` 竖条。
- 文件树顶部一个"+ 新建"行：点按 → 走 §5.4 进入写作模式开新文章。
- 空态：无任何文章时，左栏显示 `empty_paper.json` + "还没有故事，落笔写第一篇"。

### 5.2 右侧内容区：两种模式

| 模式 | 图标 | 行为 | 左栏 |
|------|------|------|------|
| **写作模式**（Write） | 折纸笔 `pen_write` | 纯编辑：标题输入 + 正文输入（多行 / 富文本），无干扰、聚焦书写 | **隐藏**（折叠收起） |
| **校阅模式**（Review/Edit） | 放大镜 `lens` | 双栏：左文件树常驻，右侧为预览渲染（可定位、可在文章间跳转、可发起编辑） | **常驻显示** |

- 右上角模式切换是一对分段按钮（笔 / 放大镜），当前态高亮 `accentVermilion`，非当前态 `inkSecondary`。
- 进入写作模式：点笔 → 触发 §5.4"文件树收起 + 笔落书写"动效。
- 进入校阅模式：点放大镜 → 文件树滑出回位（反向动效），右侧切回预览渲染，放大镜镜片做一次微缩放。
- 模式状态随当前打开的文章保持；切换文章默认进校阅模式（先看后写）。

### 5.3 文件树交互细则

- 单击纸鸟 = 在右侧打开该文章（校阅模式预览）。
- 双击纸鸟 / 点"编辑" = 直接进写作模式编辑该文章。
- 文件夹（折纸箱）单击 = 展开/折叠，盒盖动画 + 子项展开。
- 右键纸鸟（桌面端）= 上下文菜单：编辑 / 删除（`StoryRepository.delete`）/ 发布到广场（→ §6.2 发布动效）。删除走二次确认（纸张被揉皱缩小消失的 `durSaveFold` 反向意象，可选）。
- 拖拽分隔条调宽；写作模式下左栏整体向左折叠收起（不是简单隐藏，用"纸页向左翻折收起"过渡，`durFold`）。

### 5.4 进入写作模式的折叠动效

1. 点击"笔"或"新建"。
2. 左侧文件树以**左边缘为轴向左翻折收起**（`rotateY` 0→−90°，`durFold`，`curveFold`），收起后右侧编辑区平滑补满整宽（宽度补间同段进行）。
3. 收起完成瞬间，右上 `pen_write.json` 播放一次"笔尖落下书写"，正文输入框获得焦点、光标落位。
4. 退出写作（点放大镜）= 上述逆过程：编辑区让宽 → 文件树以左边缘为轴翻折回位 → 放大镜微缩放。

### 5.5 皮肤在书写界面的体现

- 正文编辑/预览区背景 = `paperBase`，并叠加当前**纸张皮肤纹理**（§8，默认无纹理纯色）。
- 文字颜色 = 当前**墨水皮肤**的 `inkPrimary`；`magicInk` 解锁后（`users.unlocks.magicInk==true`）正文笔触可启用特殊墨水皮肤（如带晕染 / 渐变），见 §8.3。
- 纹理与墨色一律走令牌，切皮肤时编辑区即时换装，无需改编辑逻辑。

## 6. 保存 / 发布 / 展开他人文章动效

### 6.1 保存 · 纸张折叠合拢（触发：保存草稿 / 保存编辑）

**触发**：编辑器点"保存"（`StoryRepository.create` 草稿或 `update`）。

**动效**

1. 当前正文区做一次"纸张沿水平中线对折再对折"的合拢动画：内容容器先绕 X 轴上下两半向中间折（`durSaveFold` 600ms，`curveFold`），折成一条，再轻微缩小 + 微透明，像把稿纸叠好。
2. 合拢定格瞬间，右下角浮出一枚小小的 `accentSeal` 折角印记 + "已保存"轻提示（`durInstant` 淡入，1.5s 后淡出）。
3. 保存成功后纸张**回弹展开**复位（折叠逆放，更快，约 320ms），可继续编辑——保存不离开页面。
4. 异步写库与动画并行：动画先行给即时反馈，落库失败则印记变 `inkSecondary` 并提示"保存失败，点此重试"。

**降级**：减少动态效果偏好下，仅显示"已保存"印记淡入淡出，跳过折叠。

### 6.2 发布到广场 · 纸鸟飞出（触发：发布 / 发布到广场）

**触发**：编辑器或文件树右键"发布到广场"（`StoryRepository.update(..., visibility:public, publishedToSquare:true)`）。

**动效**

1. 先做一次 §6.1 的"纸张合拢"把文章叠好（约 360ms 精简版）。
2. 叠好的纸张**化作一只折纸鸟**（`bird_fly.json`）：从编辑区中心起飞，沿 `curveFly` 弧线飞向屏幕右上方（朝"广场"Tab 方向）飞出，`durBirdFly`。
3. 飞出途中纸鸟逐渐缩小淡出，末端在右上角点一下 `accentVermilion` 微光（"已抵达广场"暗示）。
4. 弹出轻量成功提示"已发布到广场"，提供"去广场看看"按钮（点按走前进向翻书折叠到 `/square`）。
5. 若该文章满足官方挑战完成条件（`mode=official` 等），发布成功后**串接折纸奖励**：调 `generateOrigami`（T4.2），成功则再放一只金箔色纸鸟从右上飞回展览厅方向（暗示"获得折纸藏品"），并提示"解锁了一件折纸藏品"。

**层级 / 打断**：纸鸟在 `Overlay` 飞行，`IgnorePointer`；发布请求与动画并行，请求失败则纸鸟"飞到一半折回"落回编辑区并提示失败。
**降级**：资源缺失 → 纸张合拢 + 成功提示，跳过飞鸟。

### 6.3 排行 / 论坛列表 · 展开他人文章 · 折纸摊开（触发：列表点进详情）

> 排行界面形态：**类论坛列表**（名次 + 标题 + 作者 + 赞/评计数），数据 `StoryRepository.streamSquareFeed(sort: hotScore)`。点他人文章进详情时做"折纸摊开"。

**动效**

1. 被点的列表行作为动画源：该行卡片像一张**被折起的纸被摊开**——先沿中线"展开"放大成详情容器（共享元素式过渡：列表卡 → 详情卡，`durUnfold` 520ms，`curveUnfold`）。
2. 同段内，详情页容器以前进向翻书折叠翻正（§3.3），两者协同：外层翻书翻正 + 内层卡片摊开，给"翻开一页并把折着的内容铺平"的复合观感。
3. 摊开完成，正文自上而下错峰淡入（每段 60ms 延迟），作者行 + 计数 + 点赞按钮随后落位。
4. 返回（详情→列表）= 逆过程：正文收拢 → 卡片折回原列表行位置 → 翻书折叠后退。

**共享元素衔接**：列表卡与详情卡用同一过渡标签（hero 思路）保证"同一张纸被摊开"的连续性；标题文本在两端位置/字号补间，不闪跳。
**降级**：减少动态 → 详情页直接淡入，列表卡不做摊开。

### 6.4 论坛/排行列表视觉规格（承载 T3.1 / T3.5）

- 排行榜：每行左侧名次徽记，Top3 用 `accentVermilion`/`goldLeaf` 折角徽标，其余 `inkSecondary` 数字。
- 行内：标题（文章标题字号）+ 作者（`inkSecondary`）+ 一行摘要 + 右侧赞/评计数（`like` 图标 + 数字，`comment` 图标 + 数字）。
- 排序切换（hotScore / newest）= 顶部分段控件，切换时列表做一次轻量错峰重排淡入（不做整页翻书）。
- 计数变化（CF 1–2s 延迟）由 `Stream` 驱动自动刷新，数字变化处做一次 `durInstant` 的微跳动强调。

## 7. 性能、降级与无障碍

1. **统一动效开关**：提供一个全局"动效级别"配置（`full` / `reduced` / `off`），分别对应全动效、仅淡入淡出、几乎无动效。响应系统"减少动态效果"偏好自动降到 `reduced`。
2. **Lottie 缓存**：常用图标（纸鸟 / 箱 / 笔 / 放大镜 / 加载）首屏预解码并复用 composition，避免每次重建卡顿；列表内大量纸鸟用同一 composition 多实例。
3. **Overlay 飞行物**一律 `IgnorePointer` + 动画结束即移除，杜绝残留挡点击。
4. **转场不堆叠**：快速连续导航打断当前转场直接切，不排队。
5. **桌面输入**：所有可点元素有 hover 态（`durInstant`），分隔条 / 模式按钮 / 列表行 hover 反馈明确；键盘可达（Tab 焦点环用 `accentVermilion`）。
6. **加载兜底**：见 §2.3（骨架纸卡、8s 文案、Lottie 失败回退系统指示器）。
7. **演示视角**：所有关键动效（翻页、纸鸟、合拢、摊开）时长落在录屏"看得清又不拖沓"的区间（420–900ms），且互不重叠到糊成一团；发布→奖励等串接动效总时长控制在约 2s 内。

## 8. 皮肤系统接口（纸张皮肤 / 墨水皮肤，预留可扩展）

> 要求：**第一版就留好切换接口**，即便只内置 1 套默认皮肤。皮肤 = 一组令牌 + 资源引用的集合；切皮肤 = 整体替换令牌，页面逻辑零改动。

### 8.1 皮肤数据结构（设计层，非代码）

一套**纸张皮肤（PaperSkin）**至少包含：

| 字段 | 含义 |
|------|------|
| `id` | 皮肤唯一标识（如 `xuan_default` 宣纸、`kraft` 牛皮纸、`grid` 稿纸） |
| `displayName` | 展示名（"宣纸"/"牛皮纸"/"方格稿纸"） |
| `paperBase` / `paperShade` / `paperHighlight` | 覆盖 §1.1 对应令牌 |
| `surfaceCard` | 卡片底色 |
| `textureAsset` | 纸纹贴图资源（可空 = 纯色）；编辑区与卡片背景叠加 |
| `foldLightTint` | 折叠转场折痕受光着色（默认取 `paperHighlight`/`paperShade`） |
| `previewThumb` | 皮肤选择器用的缩略图 |

一套**墨水皮肤（InkSkin）**至少包含：

| 字段 | 含义 |
|------|------|
| `id` | 如 `pine_soot` 松烟墨、`vermilion` 朱砂、`magic_flow` 魔法流彩 |
| `displayName` | 展示名 |
| `inkPrimary` / `inkSecondary` / `inkFaint` | 覆盖 §1.1 墨色令牌 |
| `accentVermilion` / `accentSeal` | 点缀色（部分墨水皮肤可统一改点缀） |
| `strokeEffect` | 笔触特效标记（`none` / `bleed`晕染 / `gradient`渐变）；`magic_flow` 用渐变 |
| `requiresUnlock` | 是否需解锁（对应 `users.unlocks.magicInk`） |
| `previewThumb` | 缩略图 |

### 8.2 切换入口与持久化

- 切换入口放"我的"页一个"皮肤"区块（纸张皮肤 / 墨水皮肤各一排横向缩略图选择器），以及编辑器内一个快捷换肤按钮（可选）。
- 当前选择本地持久化（端上偏好存储即可，不必入 Firestore；若日后要跨端同步再考虑挂 `users` 下，本版不做）。
- 选择器中**未解锁皮肤**显示锁形 + `unlock_gold` 暗示，点按提示解锁条件（如"魔法墨水：互动分达标后解锁"）。

### 8.3 解锁联动（对齐 schema `users.unlocks`）

- `users.unlocks.magicInk == true` → 墨水皮肤选择器中 `magic_flow`（魔法墨水）从锁定变可选，并在编辑区正文笔触启用其 `strokeEffect`（晕染/渐变）；解锁瞬间可放 §2.2 `unlock_gold` 动效 + 金箔微光。
- `users.unlocks.rooms` 含某房间 ID → 展览厅对应主题房间（如禅意花园）可进入（§9）。
- 皮肤系统**只读** `unlocks`（CF 维护，前端禁写——`CLAUDE.md` §3 / schema §安全规则），仅据其布尔 / 数组决定可选性与视觉，绝不自行改写。

### 8.4 实现期约定（给 AI）

- 所有页面取色取纹理一律通过"当前皮肤"读取，**禁止**在 widget 内写死 §1.1 的字面量。
- 转场 / Lottie / 卡片 / 编辑区均订阅当前皮肤；切皮肤时通过主题刷新即时换装。
- 首版只需内置 `xuan_default`（纸）+ `pine_soot`（墨）两套并跑通切换链路，其余皮肤是后续填充。

## 9. 展览厅与主题房间视觉（承载 T4.1 / T4.3 / T4.4）

> 与 §4 入场动效配套，给静态视觉与解锁态规格；数据 `OrigamiRepository.streamMine(uid)` + `users.unlocks`。

- **画廊网格**：折纸藏品以卡片网格陈列（`Image.network(origami.imageUrl)`，**客户端不直连 Storage**——`CLAUDE.md` §7），卡片用 `goldLeaf` 细边暗示"藏品"，hover 轻微抬起 + 投影加深。每件标注 `style`（zen/steampunk/ink）小标签。
- **空态**：`empty_paper.json` + "完成官方挑战，解锁第一件折纸藏品"。

- **魔法墨水视觉彩蛋**：`unlocks.magicInk==true` 时，展览厅 / 编辑器给金箔点缀 + §8.3 的特殊笔触，呼应"墨水皮肤"。
