## 实现要点

### 写作落地页 (`WritingScreen`)

- **官方挑战卡片**：用 `ChallengeRepository.watchActive()` 实时监听当前活跃挑战。
  - 有挑战时：展示标题 + 三词 Chips + "领取挑战"按钮 → 跳转 `/writing/editor`，extra 传入 `mode=official` / `challengeId` / `words`。
  - 无挑战时：展示"暂无活跃挑战"空态。
- **自由创作卡片**：点击 → 跳转 `/writing/editor`，extra 传入 `mode=free`。

### 编辑器页 (`StoryEditorScreen`)

- **参数接收**：通过 GoRouter `state.extra`（`Map<String, dynamic>?`）获取 mode / challengeId / words。
- **模式选择**：
  - 官方挑战进入时 mode 锁定为 `official`，不可切换。
  - 自由创作进入时默认 `free`，可切换为 diary / essay / fanfic（official 不可自选）。
- **三词提示**：official 模式下顶部展示挑战词栏。
- **表单验证**：标题、正文不可为空。
- **保存草稿**：`visibility=private`, `publishedToSquare=false` → `StoryRepository.create()`。
- **发布**：`visibility=public`, `publishedToSquare=true` → `StoryRepository.create()`。
- **authorName**：提交前通过 `UserRepository.getProfile(uid)` 获取 `displayName`。
- **提交后**：SnackBar 提示 → 返回写作落地页。

### 路由

- `/writing/editor` 作为 `/writing` 的嵌套子路由（GoRouter `routes` 数组），落在 ShellRoute 内，底部导航栏仍可见。
- `StoryEditorScreen` 接收 `extra` 参数构造。
