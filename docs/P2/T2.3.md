## 实现要点

### 词库

- `kRandomWordPool`: ~80 个文学意象词，分为自然 / 物件 / 情绪 / 角色 / 场景五类。
- 全部本地常量，**不写入** `challenges` 集合（对齐 schema §设计原则 5）。

### 生成器页

- 词数可选 1 / 2 / 3 词（ChoiceChip）。
- "换一批"：`List.shuffle()` 重抽。
- "用这些词写"：跳 `/writing/editor`，extra 传 `{mode: 'free', inspirationWords: [...]}`。

### 编辑器灵感词提示

- 新 `_InspirationWordsBar` 组件：编辑器顶部显示"灵感词：xxx"。
- **关键区分**：`inspirationWords` 仅用于 UI 显示，**不会**写入 `Story.words`（后者只承载官方挑战快照）。
- 用户依然可在自由模式下切换其他子模式（diary / essay / fanfic）。

## 设计取舍

- `inspirationWords` vs `words`：spec 明确"随机词不入库"，所以 `inspirationWords` 仅作为 UI 提示，不映射到 schema 字段。
- 词库简单铺一份常量；后续若做按类目筛选，把词库改为 `Map<Category, List<String>>` 即可，UI 层加一个分类选择器。
