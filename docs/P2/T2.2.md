## 实现要点

### 官方挑战卡片增强

- **倒计时徽章** (`_CountdownChip`)：根据 `challenge.endAt` 计算 "剩 X 天 / X 小时 / X 分 / 已结束"，过期变灰。
- **本期已提交数** (`_SubmissionStats`)：用 `StoryRepository.streamByChallenge(challengeId)` 实时聚合 story 数量，验证 T2.2 验收条款。
- **"查看本期故事"入口**：跳转 `/writing/challenge/:id`。

### 挑战故事列表页 (`ChallengeStoriesScreen`)

- 顶部展示挑战标题 + 三词（`ChallengeRepository.getById`）。
- 列表用 `StoryRepository.streamByChallenge(challengeId, limit: 100)`。
- 每行：标题、正文摘要（2 行）、作者、`likeCount` / `commentCount`。
- 空态：「本期还没有故事，做第一个交卷的人」。

### 编辑器流（沿用 T2.1）

- "领取挑战" 按钮通过 `extra` 传入 `{mode: 'official', challengeId, words}`。
- 编辑器顶部"挑战词栏"展示三词（T2.1 已实现）。
- 提交时 `Story.toCreateMap()` 自动写入 `mode/challengeId/words`，schema 强约束。
