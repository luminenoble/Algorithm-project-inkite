## 实现要点

### 主屏 (`GalleryScreen`)

- 取当前 uid（`AuthService.instance.currentUid`），未登录显示「请先登录」（实际不会走到，路由守卫已拦）。
- `StreamBuilder<List<Origami>>` 吃 `OrigamiRepository.streamMine(uid)`，三态：waiting / error / data。
- 数据态：空 → `_EmptyState`；非空 → `GridView`。

### 网格

- `GridView.builder` + `SliverGridDelegateWithMaxCrossAxisExtent(maxCrossAxisExtent: 220)`，桌面端宽屏自动 4–5 列、窄屏 2–3 列。
- `childAspectRatio: 0.82`，正方形图 + 一行元信息。

### 折纸卡片 (`OrigamiCard`)

- 上方 1:1 `Image.network(origami.imageUrl)`——**客户端不直连 Storage**（`CLAUDE.md` §7），URL 由 CF 写 Firestore。
- 图片加载中 → 灰底 + 小转圈；加载失败 → 灰底 + 「破损图」图标，不抛错不空白。
- 下方风格标签（zen / steampunk / ink → 「禅 / 蒸汽 / 水墨」）+ 创建时间 `MM/DD`。
- `goldEdge: true` 时边框换金箔色 `#B8893A` + 描边加粗——T4.4 解锁视觉的钩子。

### 空态

- 折纸图标 + 「还没有折纸藏品」+ 「完成官方挑战，解锁第一件折纸」。
- 文案对齐 `fronted-design.md` §9。

## 设计取舍

- **网格用 `maxCrossAxisExtent` 而非固定列数**：Windows 桌面分辨率范围大，固定 `crossAxisCount` 在 1920 宽屏上每张卡过大、在 800 窄屏挤；用 max-extent 自动适配。
- **不实现「点开看大图 / 折纸详情页」**：当前 schema 里 `origami` 没有标题 / 故事关联文本，单开详情屏没多余信息可展。详情如需，后续可以挂在 §9 房间动效的脉络上做（与折纸藏品的「拿起来看」隐喻配套）。
- **`goldEdge` 在 T4.1 就预留**：避免 T4.4 时再回头改卡片 API，违 §0.2 接口冻结的精神。
- **不直连 Storage 的硬约束**：T4.2 折纸发放也只走 Callable 拿 URL，不在客户端 `firebase_storage`，规避 Windows 上插件支持有限的问题（`CLAUDE.md` §7）。
