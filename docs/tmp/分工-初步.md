P1 — 技术负责人 / 后端
负责整个项目的技术基座。主要工作：搭建 Firebase 项目（Auth + Firestore schema + Cloud Storage）、编写 Cloud Functions（AI 折纸生成管线、排行榜排序接口）、制定数据模型供其他人对接，后期主导全模块联调。是最先开工、最后收尾的角色，D3 前必须交付可运行空壳和数据层。
P2 — 写作核心
负责模块 B + C。主要工作：写作编辑器 UI（富文本 / 基础文本输入均可）、官方三词挑战的完整流程（领提示→写作→发布）、自由创作随机词生成。这两个模块技术难度中低，是整个 demo 的"主干流程"，必须稳且早。
P3 — 社区
负责模块 D（通道广场）。主要工作：故事发布到广场、动态列表浏览、点赞与评论功能、简单排序排行榜（非实时）。这是唯一一个等同于迷你社交网络的模块，难度高，切记做纵向切片，排行榜用 Firestore 简单查询够用，不要做实时推送。
P4 — 游戏化 + 角色查询嵌入
负责模块 E + 嵌入你已完成的模块 G。游戏化部分：展览厅画廊展示、触发条件（完成官方挑战后发放折纸）、预生成素材池接入、一个主题房间（禅意花园）的 UI；角色查询嵌入部分：将你做好的查询系统集成进 Flutter 页面，确保 Wikipedia 主源和 Reddit 缓存数据能正常渲染，无需重写逻辑。
