## A. 上传预生成素材池（必做，T1.8a 跑通的前提）

### A.1 准备图

按三种风格各准备 **3–5 张** 折纸主题图：

| 风格 | 视觉关键词 | 命名约定 |
|------|------------|----------|
| `zen` | 宣纸底、单只折纸鹤、自然光、留白 | `zen-01.png`、`zen-02.png` … 随意 |
| `steampunk` | 黄铜齿轮、纸质机械鸟、深褐羊皮纸 | `steampunk-01.png` … |
| `ink` | 水墨晕染、单色书法纸 | `ink-01.png` … |

要求：
- 推荐 PNG / JPG / WebP，正方形或近正方形
- 尺寸 ≥ 512×512，单张 < 2 MB（演示画质足够，下载快）
- 文件名仅用 ASCII 字符（避免 URL 编码问题）

> **图从哪来**：自己用任意 AI（Midjourney / SD WebUI / 在线 Flux）按上述关键词批量生成 9–15 张，挑能用的 9 张；或临时用免版权折纸照片。**这些图入 Storage 不入 Git 仓库**。

### A.2 上传

**最简单**：Firebase Console → 项目 `inkite-demo` → **Storage**（左栏）→ 默认 bucket → 进入 `Files` 视图：

1. 点 **「Create folder」**，输入 `origami` → 进入
2. 同样建 `pool` 子目录 → 进入
3. 同样建 `zen` / `steampunk` / `ink` 三个子目录
4. 在每个风格目录里点 **「Upload file」** 上传 3–5 张图

最终目录结构：

```
inkite-demo.firebasestorage.app/
└── origami/
    └── pool/
        ├── zen/
        │   ├── zen-01.png
        │   ├── zen-02.png
        │   └── ...
        ├── steampunk/
        │   ├── steampunk-01.png
        │   └── ...
        └── ink/
            ├── ink-01.png
            └── ...
```

### A.3 验证可访问

在浏览器直接打开（替换 bucket 名 / 文件名）：

```
https://firebasestorage.googleapis.com/v0/b/inkite-demo.firebasestorage.app/o/origami%2Fpool%2Fzen%2Fzen-01.png?alt=media
```

能看到图说明 OK。打不开（403）说明：
- 上传路径不在 `origami/` 下（不在 `storage.rules` 的 read:true 范围内）
- 或者 bucket 名写错

## B. 设置 Replicate API token（可选，仅在你想跑 T1.8b 实拍路径时做）

### B.1 拿 token

1. 上 https://replicate.com 注册 / 登录
2. 进 **Account** → **API tokens** → 创建一个 token（不需要绑卡，前几次调用免费额度够）
3. 复制 token，形如 `r8_xxxxxxxxxxxxxx`

### B.2 设到 Firebase Secrets

在仓库根目录跑：

```bash
firebase functions:secrets:set REPLICATE_API_TOKEN
```

CLI 会进入交互模式让你粘贴 token 值。粘完按回车确认即可。

> **绝不要把 token 写进 `functions/.env` / `package.json` / 任何入仓文件**（`CLAUDE.md` §3 + `.gitignore` 已防）。

### B.3 让函数知道有新 secret

`generateOrigami.ts` 里已经 `defineSecret('REPLICATE_API_TOKEN')` 并在 `onCall({secrets:[...]})` 中声明。secret 设置完后必须**重新部署一次** generateOrigami，让 secret 注入运行时（见 §C）。

如果跳过 B，T1.8a 单路径仍能完整跑——`live: true` 调用会被自动降级回池，行为不变。

```
✔  functions[generateOrigami(asia-east1)] Successful create operation.
```

部署完检查：

## D. 验证（必做，演示前一定要走一遍）

测试至少两条 path——**生产真调** + **降级兜底**。可以借 Firebase Console 的「Test function」直接调，不必动 Flutter。

### D.1 准备数据

在 Firestore Console 用你的真实账号：

1. 找一条你创建的、`mode='official'`、`publishedToSquare=true` 的 story
2. 抄下它的 `challengeId`（不是 storyId！）
3. 抄下你登录后的 uid（`/me` 页面有显示，或 Auth 控制台找）

### D.2 通过 Cloud Console「Test function」调用

> 在 GCP Cloud Console 测 Callable function 不会带 auth，所以走 emulator 兼容路径需要 **`__testUid`**。但生产部署的函数没设置 `FUNCTIONS_EMULATOR=true`，`__testUid` 不会生效——下面的 D.3 走 Flutter 调比 D.2 简单。

如果一定要在 Console 调：函数页面的「Testing」入口对 v2 Callable 支持有限，推荐 D.3。

### D.3 通过 Flutter 临时一行代码调

T4.2 还没做，所以暂时在任意可点按钮上挂一段：

```dart
// 临时验证用，验证完删
import 'package:cloud_functions/cloud_functions.dart';

Future<void> _tempTestOrigami() async {
  final fn = FirebaseFunctions.instanceFor(region: 'asia-east1')
      .httpsCallable('generateOrigami');
  try {
    final r = await fn.call({
      'challengeId': '<你的真实 challengeId>',
      // 'live': true,   // 取消注释跑 T1.8b 实拍
    });
    debugPrint('origami result: ${r.data}');
  } catch (e) {
    debugPrint('error: $e');
  }
}
```

需要在 `pubspec.yaml` 加：

```yaml
dependencies:
  cloud_functions: ^5.1.3   # 与 firebase_core 6.x / firestore 5.x 兼容
```

然后 `flutter pub get`、`flutter run -d windows`，在你写的临时按钮上点一下。

**预期返回**（T1.8a 路径）：

```json
{
  "origamiId": "abc123...",
  "imageUrl": "https://firebasestorage.googleapis.com/v0/b/.../o/origami%2Fpool%2Fzen%2Fzen-03.png?alt=media",
  "style": "zen",
  "source": "pregen"
}
```

去展览厅看，应该立刻多出一件折纸藏品（T4.1 网格自动响应 `streamMine`）。

### D.4 验证清单

按顺序勾掉：

- [ ] **首次调用成功**：返回 `source='pregen'`，`origami/{id}` 落库，画廊可见
- [ ] **图片能加载**：画廊里图片正常显示（说明 Storage URL 没问题）
- [ ] **幂等**：同一 `challengeId` 再点一次 → 返回**同样的** `origamiId`，画廊没多出第二件
- [ ] **防刷**：换一个根本没发布过故事的 `challengeId` → 收到 `failed-precondition` 错误，画廊无新增
- [ ] **T1.8b（可选）**：调用时传 `'live': true`，B 已设 secret → 返回 `source='flux'`，Storage `origami/live/{style}/` 多一张新图，画廊该件折纸用的是这张新图
- [ ] **降级（可选）**：临时把 Replicate token 改错（`firebase functions:secrets:set REPLICATE_API_TOKEN` 设个无效串）→ 调 `'live': true` → 仍返回 `source='pregen'`，没 5xx 错误。**验完别忘了把真 token 设回去**

## 排错速查

| 症状 | 原因 / 处理 |
|------|-------------|
| `failed-precondition: 素材池 origami/pool/zen/ 为空` | A 没做完，或上传到了错误路径 |
| `failed-precondition: 需先完成并发布该官方挑战的故事` | 防刷生效，正常；先去写一篇官方故事 + 发布到广场 |
| 调用返回成功但画廊没变 | 检查 `streamMine` 的 ownerId 字段是否与当前 uid 一致；Firestore Console 看 `origami/{id}.ownerId` |
| `live: true` 但 source 还是 pregen | secret 没设 / 部署后没生效（C 的部署要在 B 之后）/ Replicate 4xx — 看 §E 日志 |
| 图片 URL 在浏览器打开 403 | `storage.rules` 当前已部署 read:true 不应出现；若已收紧到 isSignedIn 需带登录态访问 |
| 函数没出现在 Functions 列表 | 检查 `npm run build` 是否成功；`index.ts` 是否导出 `generateOrigami` |
