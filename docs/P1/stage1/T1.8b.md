## 密钥管理（Firebase Functions Secrets）

```typescript
import { defineSecret } from "firebase-functions/params";

const REPLICATE_API_TOKEN = defineSecret("REPLICATE_API_TOKEN");

export const generateOrigami = onCall<GenerateRequest>(
  { secrets: [REPLICATE_API_TOKEN] },
  async (request) => { ... }
);
```

- **绝不入仓**：仓库内搜不到任何 Replicate token 明文（`CLAUDE.md` §3）。
- **设置方式**：`firebase functions:secrets:set REPLICATE_API_TOKEN`（人工动作见 `T1.8-manual-ops.md`）。
- **读取**：函数内 `REPLICATE_API_TOKEN.value()` 取，未设置时 `tryReplicate` 抛错并被降级捕获。
- **存储**：Secrets 走 Google Cloud Secret Manager，按调用次数计费，本 demo 体量内免费额度内。

## Replicate Flux Schnell 调用

### Prompt 设计

按风格固定 prompt，匹配 schema 的三种 `style`：

| style | prompt |
|-------|--------|
| `zen` | minimal origami crane, cream rice paper background, soft natural lighting, paper texture, top-down studio photo, no text |
| `steampunk` | steampunk origami mechanical bird with tiny brass gears and copper wires, on aged parchment, dramatic side light, no text |
| `ink` | ink wash origami crane in sumi-e style, calligraphy paper background, monochrome black ink, no text |

每个 prompt 都加「no text」防止 Flux 把汉字 / 英文符号画进图。

### API 调用

```typescript
const res = await fetch(
  "https://api.replicate.com/v1/models/black-forest-labs/flux-schnell/predictions",
  {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${token}`,
      "Content-Type": "application/json",
      "Prefer": "wait",     // 同步等结果；Flux Schnell 单图 1–2s 远低于 60s 上限
    },
    body: JSON.stringify({
      input: {
        prompt: prompts[style],
        aspect_ratio: "1:1",
        output_format: "png",
        num_outputs: 1,
      },
    }),
    signal: controller.signal,
  },
);
```

- 用 `Prefer: wait` 同步等结果，避免轮询；Flux Schnell 平均 1–2s 出图，远低于 60s sync 上限。
- 全程 `AbortController` + 20s 超时，超时直接抛错走降级。

### 出图后落地

```typescript
const buf = Buffer.from(await imgRes.arrayBuffer());
const bucket = getStorage().bucket();
const objectName = `origami/live/${style}/${Date.now()}-${random6}.png`;
await bucket.file(objectName).save(buf, { contentType: "image/png" });
return firebaseDownloadUrl(bucket.name, objectName);
```

- 路径 `origami/live/{style}/`，与预生成池 `origami/pool/` 同根（共享 `origami/{file=**}` read 规则）。
- 文件名 `timestamp-random6.png` 避免冲突。
- URL 同样走 Firebase Storage 免 token 下载 URL。

## 降级策略

```typescript
if (live === true) {
  const liveUrl = await tryReplicate(style).catch(err => {
    logger.warn(`[generateOrigami] Replicate failed, falling back to pool`, err);
    return null;
  });
  if (liveUrl) { imageUrl = liveUrl; source = "flux"; }
  else         { imageUrl = await pickFromPool(style); source = "pregen"; }
}
```

**触发降级的情形**：

| 失败原因 | 行为 |
|----------|------|
| `REPLICATE_API_TOKEN` 未设置 | 抛 `Error("...secret not set")` → 回退池 |
| Replicate API 4xx/5xx | 抛 `Error("Replicate API ...")` → 回退池 |
| Replicate 返回结构异常 | 抛 `Error("Replicate returned no image URL")` → 回退池 |
| 20s 超时 | `AbortError` → 回退池 |
| 图片下载失败 | 抛 `Error("download image failed")` → 回退池 |
| 弱网（演示当天最大风险） | 同上 |

降级永远成功（前提：池里至少一张图），客户端拿到的 `imageUrl` 永远可用，**演示弱网不阻塞**。

## 设计取舍

- **`live` 入参 vs 单独 Callable**：选合一。优点是客户端调用形态统一；缺点是 token 注入要给整个 Callable（每次冷启动多 1 次 Secret Manager 读取）。Demo 体量下成本忽略，统一性收益更大。
- **`Prefer: wait` 同步等而非轮询**：少一次往返、客户端代码简单。Flux Schnell 的同步上限远高于其实际生成时长，安全。
- **降级总是回到池**：不再往上抛错给客户端，避免「等了 20s 又看到 toast 失败」的演示翻车。日志里 `logger.warn` 留痕，演示后复盘可见。
- **路径 `origami/live/` 与 `origami/pool/` 平级而非同目录**：演示后清点哪些是实拍、哪些是预生成只看路径即可，运维友好。
- **不实现「live 失败的客户端可见反馈」**：演示叙事里实拍是「奖励」，不该让用户感知到「失败回退」，UI 上从来不区分 `source`。CF 日志兜底足够。
