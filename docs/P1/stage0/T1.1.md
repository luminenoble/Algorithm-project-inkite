## 需 P1 在 Firebase Console 完成的动作

### 1. 创建项目

1. 打开 https://console.firebase.google.com
2. **添加项目** → 项目名 `inkite-demo`
3. 套餐：先选 **Spark（免费）**，Functions 部署前再升级 **Blaze**（按用量付费，demo 量级落在免费额度内）
4. 启用 Google Analytics：**否**（演示项目不需要）

### 2. 启用服务

进入项目后依次启用：

- [ ] **Authentication** → Sign-in method → 启用 **Anonymous** 与 **Email/Password**
- [ ] **Firestore Database** → 创建数据库 → **Native 模式** → 区域 `asia-east1`
- [ ] **Storage** → 开始使用 → 区域 `asia-east1`（与 Firestore 同区）
- [ ] **Functions**（先不部署，T1.7/T1.8 用到时再升 Blaze）

### 3. 区域一致性

**所有服务统一选 `asia-east1`**。Cloud Functions 在 T1.7 部署时也指定同一区域，避免跨区延迟与额外费用。

### 4. 预算告警（升 Blaze 后立即设置）

- Google Cloud Console → Billing → Budgets & alerts
- 月度预算 **¥50** 或 **$7**
- 阈值告警：50% / 90% / 100%

### 5. 注册 Android App

1. 项目概览 → 添加应用 → Android
2. 包名：`com.inkite.app`
3. 下载 `google-services.json`
4. **暂不放入仓库**，等 T1.3 执行 `flutter create app-storage` 之后放到 `app-storage/android/app/google-services.json`
5. 在终端确认它已被 `.gitignore` 屏蔽：`git check-ignore -v app-storage/android/app/google-services.json`

### 6. 核对 `.firebaserc`

若实际项目 ID 不是 `inkite-demo`（如 `inkite-demo-a1b2c`），用 firebase CLI 同步：

```
firebase login
firebase use --add
```

或直接编辑 `.firebaserc` 把 `default` 改成真实 ID。
