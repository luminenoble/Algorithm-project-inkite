## `firestore.rules` 设计要点

### 工具函数

- `isSignedIn()` / `isOwner(uid)`：登录态与所有权
- `counterFieldsUntouched()`：`update` 时禁止前端动 `likeCount / commentCount / hotScore`（仅 CF 可写，对接 T1.7）
- `counterFieldsZeroOnCreate()`：`create` 时强制三个计数从 0 起步（禁止前端自塞高值刷榜）

### 按集合权限矩阵

| 集合 | read | create | update | delete |
|------|------|--------|--------|--------|
| `users/{uid}` | 任何登录 | 仅本人 | 仅本人（dev 暂不锁 stats/unlocks，T1.10 收紧） | 禁止 |
| `challenges/{id}` | 任何登录 | 禁前端 | 禁前端 | 禁前端 |
| `stories/{id}` | 登录 + (public 或 自己) | 登录 + author=自己 + 三计数=0 | author=自己 + 不动三计数 | author=自己 |
| `stories/{id}/comments/{cid}` | 任何登录 | 登录 + author=自己 | 禁止（MVP 不许编辑） | author=自己 |
| `stories/{id}/likes/{uid}` | 任何登录 | 仅本人（uid=docId） | 禁止 | 仅本人 |
| `origami/{id}` | 任何登录 | 禁前端 | 禁前端 | 禁前端 |
| `charactersCache/{key}` | 任何登录 | 禁前端 | 禁前端 | 禁前端 |
| `_probe/{uid}` | 仅本人 | 仅本人 | 仅本人 | 仅本人 |
| 其他路径 | 兜底拒绝 | 兜底拒绝 | 兜底拒绝 | 兜底拒绝 |

### `_probe` 集合的处置

`_probe/{uid}` 是 T1.3 端到端连通性探针的落点。本次规则把读写收口到 `isOwner(uid)`——比 T1.3 时的 deny-all 收紧、比线上正式规则宽。

**T1.10 收尾时**：连同集合 + 规则一并删除；正式 demo 不留这个调试痕迹。

### 故意没做的事（留给 T1.10）

- `users.stats.*` / `users.unlocks.*` 字段级 CF-only 约束：dev 期允许本人随手测；T1.10 收紧
- `stories.visibility` 枚举校验（必须 `'public' | 'private'`）
- 字段类型/长度校验（`title` ≤ 100、`body` ≤ 8000 等）
- `challenges.words` 必须长度 = 3

## Emulator 启动方法（团队共用）

> WSL2 下首次启动需要下载 Firestore / Storage / Auth 的 JAR（每个 50–150 MB）。**本机当前 JAR 下载受 WSL 网络限制卡住**，建议在 Windows 端做主要本地联调（与 T1.3 的 Windows 主开发路径一致）。下载只是一次性。

### 在 Windows PowerShell

```powershell
cd D:\wsl-share\Algorithm
firebase emulators:start --only firestore,storage,auth
```

首次运行 firebase-tools 会下载 JAR 到 `%LOCALAPPDATA%\firebase\emulators\`。下载完毕后：

- Firestore Emulator → `localhost:8080`
- Storage Emulator → `localhost:9199`
- Auth Emulator → `localhost:9099`
- Emulator UI → http://localhost:4000

### 在客户端（`app-storage/lib/main.dart`）切到 Emulator

T1.4 暂不写代码，但记录方法供 T1.5 / T1.6 接 Emulator 时用：

```dart
// 在 Firebase.initializeApp 之后立即调用（仅 debug 期）
if (kDebugMode) {
  FirebaseAuth.instance.useAuthEmulator('localhost', 9099);
  FirebaseFirestore.instance.useFirestoreEmulator('localhost', 8080);
  await FirebaseStorage.instance.useStorageEmulator('localhost', 9199);
}
```

### 端口约定

在 `firebase.json` 已固定。任何团队成员本地起 emulator 都用同一组端口，避免文档分叉。

### 数据隔离

Emulator 默认每次启动**内存态**，重启清空。需要持久测试数据可加：

```
firebase emulators:start --only firestore --import=./.emu-data --export-on-exit
```

`./.emu-data` 已被仓库根 `.gitignore` 的 `.firebase/` 规则间接覆盖；不会误入仓。
